# TrabajoTP_Martes

Proyecto de cafeteria en Java 17, Spring Boot y MySQL.

El codigo, las instrucciones y la documentacion estan en [CafeJava](CafeJava/README.md).

## Iniciar desde PowerShell

```powershell
cd "C:\Users\lopez\Desktop\TrabajoTP_Martes\CafeJava"
.\iniciar.cmd mysql
```

La aplicacion se abre en http://localhost:8081. Para una base de demostracion independiente, usar `.\iniciar.cmd demo`.

La configuracion privada `application-local.properties`, los datos y respaldos de `runtime/` y los archivos compilados de `target/` no se incluyen en Git. Para configurar otra instalacion, consultar las instrucciones de CafeJava.
